# Vertex Design - Design Fee Calculator

Corporate-grade, design-only pricing portal for management and procurement teams. Everything runs locally inside the `index.html` file - no backend services or external libraries.

## Getting Started
1. Keep all files inside `E:\PRCINING PORTAL` as provided.
2. Double-click `index.html` (or open it via your browser's **File -> Open** dialog) to launch the calculator.
3. Enter project data to trigger live fee calculations, copy/share/download the quote, or print to PDF.

## Editing Pricing Rules
- All commercial logic lives in `assets/config.json`. Update base fees, area rates, multipliers, add-ons, and rollout factors there.
- Use `assets/config.example.json` as a safe template when preparing alternative pricing sets - copy it to `config.json` and then insert real values.
- After saving changes, refresh the browser tab to reload the latest configuration.

## Switching `public_mode`
- The UI respects the `publicMode` flag located at the top of `assets/config.json`.
    - `true` -> budgetary range only (no breakdown or raw rates).
    - `false` -> full internal breakdown plus exact totals.
- Toggle the flag, save the file, and refresh the browser to apply the new mode.

## If Config Loading Is Blocked
- Some browsers block local file access for security. If you see a config load warning, click **Select Config File** and choose `assets/config.json`.
- You can also run a simple local server (for example, `python -m http.server`) and open `http://localhost:8000` to allow automatic loading.

## Publishing & Sharing
- When distributing the portal externally, always confirm `publicMode` is `true` so sensitive rate tables never surface.
- Share links generated by the UI only encode user inputs (project data) and never embed pricing figures.
- Reminder: every quote view includes the disclaimer **"Budgetary estimate only. Final fixed fee issued after scope confirmation."**
